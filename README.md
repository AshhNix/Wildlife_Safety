# 🌲 WILDCARD AI

AI-Powered Wildlife Protection & Road Safety Monitoring System

## Overview

Wildcard AI is a computer vision-based monitoring platform
designed to support wildlife conservation, forest security,
road safety, and environmental hazard detection.

## Features

- Human intrusion detection
- Wildlife identification
- Wildlife road-risk monitoring
- Environmental hazard monitoring
- AI-powered object detection
- Risk classification
- Automated alert generation
- Detection event logging
- CSV export
- Annotated image output

## Technologies

- Python
- Streamlit
- YOLOv8
- OpenCV
- NumPy
- Pandas
